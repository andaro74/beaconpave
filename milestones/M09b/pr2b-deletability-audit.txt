M09b PR 2b — deletability audit, at CHECK granularity
======================================================

Method: mutate the PROPERTY a check protects, assert the mutation is live (the old
substring occurs exactly once before and is gone after, the new one is present),
run the check, record what fires. Working copies backed up to a temp directory as
bytes and restored FROM THERE, never `git checkout --`; every restore is asserted
to reproduce the original SHA-256. `git status --short` was empty after both passes.

Two passes:

- PROPERTY (P1-P18): the plant, run against the test files that own the property.
  A red there makes the gate red, and a full gate run per plant adds nothing to that
  fact. The failing cases are named.
- GATE (G1-G4): the plant AND the check that catches it disabled together (the test
  function renamed so pytest does not collect it), run through the GATE —
  `python -m pave.cli check`, not `pytest tests/`. Gate PASS means nothing else in
  the suite holds that property: the check is unique, not dead. Paired with the
  property pass showing it bites, that is a live check.

Harness: a scratchpad script, not committed; every mutation is quoted below.

Tree: every plant ran against the head of branch m09b-pr2b-readings-and-corpus
after its ninth commit (subject: "the rule gaps closed in the diff that creates what
they cover, with a plant each"), before the journal, this file, the ADR amendment
and the PR body were added.

Gate baseline on that tree: `python -m pave.cli check` PASS, 4620 passed, 8 skipped,
148.33s.
