### The terminal state

`state` holds exactly one of two values, and either one names no target milestone. For an owe
the target field is `re_deferred_to`; for an act it is `owed_by`. The history fields
(`originally_due`, `deferred_from`) are not targets, and the ratchet still reads them.

| state | must carry | refused when |
|---|---|---|
| `UNSCHEDULED` | `owners` (non-empty list of non-blank strings), `trigger` (non-blank) | no owners, an empty or blank owner, no trigger, or a target milestone, open or closed |
| `RETIRED` | `retired_by` (an ADR, by `twokey.adr_defect`), `disposed_by` (exactly two distinct seats, both on the registry's own two-key rule) | no ADR, a non-ADR path, one seat, one seat twice, a seat off that rule, or a target milestone |
| anything else | — | any other value, including `""` |

PAID keeps the form it already had. For an act that is `recorded`, a path its test resolves.
For an owe there is none (flag 4).
